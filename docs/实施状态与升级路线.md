# 实施状态与升级路线

版本：0.1.0；更新：2026-10-12；范围：基础实现状态与后续编辑规划。

## 2026-10-12 左侧工具箱重新规划

新增[按格式重构左侧工具箱需求](./design/LEFT_TOOLBOX_REQUIREMENTS_2026-10-12.md)，从任务／对象模型重新组织 Markdown、Word、PPT、Excel、PDF 与本地 HTML，不沿用现有“目录／查找／工具”分类。PPT／PDF 以真实缩略图和页面组织为核心，Word／Markdown 以结构、样式和写作为核心，Excel 以工作簿、范围、公式和数据为核心。文档包含完整工具组、属性交互、稳定目标、统一命令注册表、MCP schema／回执／并发与 16 类验收场景，并附各格式详细矩阵。远程网页默认无常驻左栏。**本段为需求设计，新左栏尚未实施。**

最新材质范围：普通侧栏、设置控件、搜索框、提示等使用轻量磨砂玻璃；统一导航、Agent 底部操作胶囊和右侧 AI 结果／选区译文小浮窗使用完整正文折射，AI 抽屉本体仍为磨砂。[交互更新记录](./design/UI_POLISH_2026-10-12.md)包含工具迁移、11 项 AI 阅读工具、优雅动画和本机同步验收。完整新左栏分类、真实缩略图和高级编辑功能仍按需求分阶段实施。

## 2026-10-12 全面编辑规划

已完成当前编辑代码审计并新增[全面编辑能力规划](./design/EDITING_CAPABILITIES_PLAN_2026-10-12.md)，包含 Markdown 对标 Typora、Office 对标 Writer/Calc/Impress、PDF 完整工具、统一命令/历史/锚点与 harness 接口。全部内置约束下，Office 优先验证 LibreOffice UNO 原生 host；PDF 主线为 PDF.js 阅读层与 MuPDF 本机编辑内核。Windows 内嵌、源码保真、PDF 原文修改与许可证路线均有明确验证门槛。

该段记录规划初始轮；随后已接入下列 Office 增量。以下 2026-10-10 与 2026-10-09 段落保留各轮实施证据；完整编辑实施顺序继续以新规划的 S0–S7 为准。

## 2026-10-12 Office 工具增量

Word 已实现选区丰富文字格式、段落间距/缩进、段落删除、真实表格与表格文字、分节方向/边距；PPT 已实现页序增删复制移动、文字对象增删与样式/位置、背景、独立备注；Excel 已实现范围格式/边框/换行、单事务 TSV 粘贴、合并/解除、行列增删/宽高、工作表删除、冻结、筛选和数据排序。对应 operation、读取字段与边界见[规划 2.1](./design/EDITING_CAPABILITIES_PLAN_2026-10-12.md#21-2026-10-12-已实现的-office-增量)。所有新增操作由同一 `editOperationSchema` 校验，经 MCP `document_plan_patch/document_apply_patch` 开放给 harness。

`tsc --noEmit` 与 Office 专项纯测试已通过，专项验证真实提交、条件撤销、保存、新 Core 从文件重开、未改部件、拒绝路径与草稿异步语义。最新联合纯测试为 **92/92**。内置 LibreOffice 在独立临时 profile 中成功解析最终 DOCX/PPTX/XLSX 并导出非空 PDF；阅读交互、设置组件、完整 Office UI、100%／150%／200% native 浮窗、优雅动画、渲染复用、真实单实例恢复与安装版同步均已验收。[交互更新记录](./design/UI_POLISH_2026-10-12.md)保留最终构建与独立证据目录，不将基础样本推广为全部复杂文件保真。

Office 已接入草稿注册表：正文、单元格、公式栏和备注在保存/切页/关闭前提交，IME、失败、来源冲突及提交期间继续输入保留草稿并阻止退出。主进程原生关闭使用确认握手，失败不销毁窗口；最近撤销事务按文档记录。Excel 的中文/Unicode 表名引用在改名、删除与行列调整中统一识别，字符串和函数不误改，外部链接/三维及未知引用拒绝。harness 的 `before-agent-edit` 草稿检查在已完成幂等返回之后、文档提交队列之前执行；有未提交人类输入时拒绝 Agent 修改，不强制提交人类草稿，检查期间的人类提交仍由版本校验保护。

Word 当前为连续纸张流；Excel 不提供公式计算，数据变更清理缓存并要求重算，复杂包与不安全的合并/公式结构操作拒绝；PPT 删除保留孤立部件。原生 Office 会话、真实分页、完整对象/审阅、公式重算和目标级历史仍在后续路线中。

共同正文缩放（25%–400%、`view.zoom`、MCP `reader_set_zoom`）、`FileDropHost` 与原生网页隔离 preload 已接入，并通过本轮阅读交互回归。[独立设置窗口改造](./design/SETTINGS_REDESIGN_2026-10-12.md)完成分组布局、右对齐紧凑开关/枚举、即时保存与全局撤销、单调 revision、按需材质预览和未接入选项折叠，组件交互已通过。渲染增加完整字段 sharing、Office memo、像素/PNG 复用与双预算 LRU；[真实性能证据](./design/RENDERING_PERFORMANCE_2026-10-12.md)验证网页 3 次重复 capture 没有新编码或图片发送，三种 Office 各 8 次真实 poll 没有新增正文执行。尚无 FPS 前后基准，缓存解码预算不代表 GPU 总内存。

## 既有实现概况

本轮已经从设计文档建立应用和共享接口，能够实际打开、修改并保存现代必选格式的基础内容。它仍未通过完整需求中的所有 P0；下表同时列出已完成闭环和剩余能力，避免用基础文字编辑代替完整 Office/PDF 验收。

本机新增 Windows x64 内置资源：BabelDOC 0.6.4 及 Python/版面缓存、LibreOffice 26.8.1、Tesseract.js 7.0.0 中英文字库。`engines:verify`、`test:engines` 分别通过资源检查、PDF 模型桥翻译和 DOC/PPT/XLS 转换往返；`engines:stage` 把资源复制到发行目录。它们解决 PDF 翻译、旧格式转换和 PDF 页面 OCR，尚不构成完整 Office 所见即所得编辑引擎。内置资源版本、摘要和许可证见 `engines.lock.json`。

## 2026-10-10 交互与翻译增量

本轮在基础版本上实际接入了主页、按格式展开/收起的左侧工具、液态玻璃操作胶囊、按需 AI 抽屉，以及单独的设置窗口。阅读页两侧为悬浮圆角面板，本地文档顶部只有不占整行的悬浮胶囊；PDF 的增补、高亮、旋转、增页和 OCR 均进入左侧格式工具，识别结果也在侧栏。左侧活动栏分别使用结构、搜索和工具图标。本地文档显示文件名，网页显示地址。设置可切换五种阅读背景，背景不写入文档。设置使用版本化 JSON 和跨窗口通知；已接通的偏好即时或按标注时机生效，尚未接入的控制项显示依赖并禁用。界面当前仅针对横版桌面视口设计。

导航入口已收敛：左上角品牌标识是唯一主页入口，顶部齿轮是唯一可见设置入口；新建文档在主页使用主操作，在阅读页使用标签加号；源码/分栏与网页翻译只保留顶部操作胶囊入口。左侧活动栏只负责格式面板切换和收起，右侧翻译图标负责查看译文，AI 工具中的“翻译选区”负责发起动作。

## 验证证据

`npm.cmd run build` 已通过：TypeScript 检查、Electron/preload/MCP 打包、Vite 生产构建。CodeMirror 和 PDF 引擎采用延迟加载；CodeMirror 单块约 607 KB，构建有 chunk size 提示，尚未执行完整容量/启动 P95 基准。

`npm.cmd test` 的 9 项核心/集成测试通过，覆盖未保存快照、独立视图、固定问题内容、过期修改拒绝、并发幂等/重启回执、文件冲突与保存、保守撤销、Office ZIP 部件、PPT 实际页序、XLSX 公式与 PDF 持久操作、HTTP 认证/Origin/actor 边界。

`npm.cmd run test:desktop` 使用真实 Electron、临时样本和本地交互网页，已通过：

- Markdown 选择、源码输入、分栏、保存，并检查实际文件。
- DOCX/PPTX/XLSX 界面编辑后保存，重新解析文件验证变化。
- PDF 中文增补进入真实文字层；页面新增保存为四页。
- HTML 源码原文保存、移除原脚本的安全预览、可见文本更新。
- 原生网页点击、中文输入、End 按键、拖动选择、滚轮、幂等重试、旧导航/视口拒绝、PNG 截图。
- 插件发现启动器连接真实 MCP；返回阅读上下文和 image 内容块。
- 外部 Origin 拒绝；网页进程访问本地 API 被阻止；敏感字段过滤和阅读副本脚本移除。
