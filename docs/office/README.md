# 原生 Office

Windows 通过 LibreOfficeKit 加载 Writer、Calc、Impress。每份文档有唯一原生模型，各视图绑定 controller；图块、选区与真实修改来自引擎，不能用辅助 OOXML 镜像代替它。

## 目标与单位

文字目标绑定原生容器与 UTF-16 范围；Excel 绑定工作表和地址；PPT 绑定递归对象路径及文字范围。对象选中与对象内部文字是不同目标，不能搜索同名文字猜选区。

原子 inspect 同时读取状态、属性和命令能力。混合格式保留 mixed，无法读写的字段报告 unsupported。尺寸和对象位置使用 mm，字体/线宽使用 pt；内部旧几何的1/100mm不直接泄露为公开参数。

Word 可见文字先由原生页游标限定页面范围，再测量段落，按内容版本和页区间缓存。跨页表格按所在单元格与行取范围，巨段裁切到页面边界；不再为每次点击和编辑测量全文前2000段。探测 controller 不改变人工选区或撤销历史，表格选择使用原生 CellName 身份。

Word 页样式须明确命名，禁止从人工当前页推断；Calc 由原生引擎解释输入并计算公式。辅助 ExcelJS 投影的1000×50读取限制不代表原生 Calc 的容量上限。

Calc 布尔常量保留原生 LOGICAL 类型，数字覆盖时清除旧逻辑格式。区域读回含 values、formulas、errors、kinds 和 logical；公式的逻辑结果类型若无法确认则为 null，不根据公式字符串猜测。

## Agent 与人工协作

普通模型操作默认后台执行。后台语义 controller 必须具备完整生命周期、事件、历史和修改通知；只有 view id 不足以安全复用执行器。不可隔离时明确返回能力限制。

活动标签由明确的打开、切换或输入入口决定。被动状态、轮询、布局及迟到回执不能根据旧的 focused/actor 标志重新激活文档，避免新文件已加载却被旧页抢回。

PPT 文本必须保留真实 Outliner 修改/撤销事务，不能仅给 shape.String 赋值就宣称成功。后台编辑还需证明人工页、选择与编辑状态未改变；不满足时拒绝操作。

人工普通文字编辑不能一概禁用属性查询；组合输入、在途事件与模态状态则遵守输入保护。选区与布局版本只在操作实际依赖时检查，避免纯模型编辑因视口移动失效。

## 回执与保存

派发、应用、验证、恢复检查点和磁盘保存分别报告。Agent 编辑默认执行后读回目标；显式保存冻结版本并检查源文件冲突。独立导出创建新文件，校验可解析结果，不改变源位置。

原生撤销核对当前 token 与版本。UndoContext 只能组织历史，不能承诺批量失败后自动原子回滚。失败后先读取真实状态，不自动重放已派发写入。

## 调度与边界

原生顺序屏障间优先交互，合并可替代读取；已经开始的 LibreOffice 调用不能抢占。大 OOXML 投影进入有界 worker，图块采用有界缓存和二进制传输。空闲预热按加载、初始化、首瓦片阶段让路。

启动时，私有配置和资源的完整校验与 DLL 加载并行，在原生 hook 前汇合；不跳过校验。快照逐视图检查真实输入状态，不为此重建每个视图的全文投影；服务层复用同一串行操作内已验证的摘要。PPT 仍通过隔离只读 ODP 副本导出，保留原文颜色与撤销保护；仅临时 ODP 关闭文件同步，最终输出保持校验和发布。

内部可绘制几何与公开 presented/obscured 状态分离，避免首帧退到心跳重试。启动计时分别报告排队、加载、初始化、首瓦片和呈现，不能把单段计时当作可编辑总耗时。

修订/评论、图表/透视/验证、母版/动画已有原生 UI；结构化 API 以实际 capability 和读回为准。复杂排版、字体及特殊控件仍需文件样本。
