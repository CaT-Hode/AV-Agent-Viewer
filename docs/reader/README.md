# 阅读与交互

面向横版桌面。主页管理最近文档、示例和译文；新标签页搜索接受文件名、本地路径和网址。异步打开替换发起请求的新标签，不应抢走用户随后选中的页面。

## 视图与工作区

每个视图独立保存位置、选区、缩放和模式。顶部导航控制当前页；Ctrl+L 聚焦地址/搜索，Ctrl+, 打开设置。Markdown 使用 Ctrl+P 快速打开、Ctrl+Shift+F 搜索工作区全文，文件树按需展开；删除移入可撤销回收区。

Markdown 阅读模式是可编辑实时装饰，源码保留标记，分栏共享只读虚拟预览。表格、脚注、YAML、公式等编辑写回同一份源码；预览选区映射到精确源范围，无法确认时不提供写操作。左栏提供格式、代码语言、资源及偏好；导出基于完整文档。

PDF 使用真实画布与文字层；OCR 标明页和识别来源。Office 使用[原生编辑器](../office/README.md)，对象与内部文字选择分别处理。正文缩放与界面缩放独立，背景设置不写入文件页面。

## 悬浮工具与视觉

选区工具首先提供按钮和低成本材质；交互不等待玻璃纹理、原生背景采样或入场动画。折射纹理在 Worker/OffscreenCanvas 生成，尺寸稳定后更新；繁忙或不支持时保持同布局 CSS 表面。普通控件沿用轻材质，尊重关闭玻璃、降低透明度和减少动态效果设置。

导航和侧栏使用合并几何测量，文字、标签及按钮不接受背景滤镜。视觉简化不能改变目标范围或隐藏功能。

## 网页与来源

网页运行于独立 Chromium WebContentsView；输入使用 CSS 像素及当前 navigationId/layoutRevision。截图位图像素不能直接作为点击坐标；导航、翻译和尺寸变化后重新读取。

本地 HTML 副本净化脚本与敏感表单值，引用资源可能仍访问网络。当前页面读取不能推导为完整跨 frame 语义覆盖或离线归档。

本轮 Reader 已验收编辑、撤销、保存、三模式选区、本地图片、公式图表与实际导出；主页覆盖异步导航及设置。具体范围见[测试](../../tests/README.md)，系统拼音输入法与复杂文件仍需独立验收。[编辑能力](../editing/README.md) · [性能](../performance/README.md)
