# 阅读与交互

默认面向横版桌面。主页管理最近文档、示例和译文；搜索接受文件名、路径和网址。异步打开只完成发起请求的标签，不抢走用户随后选择的页面。Ctrl+L 聚焦搜索，Ctrl+, 打开设置。

## Markdown

实时、源码与分栏共用源码和范围历史。分栏预览只读，选区精确映射回源码后才能修改。切换、关闭和导出先排空草稿；迟到回执不覆盖更新的选择。

Ctrl+P 快速打开，Ctrl+Shift+F 搜索工作区。文件树按需展开，切换文件树/快速打开时保留展开、选中、查询并重新测量面板高度。空正文、输入及再次清空保持同一纸宽。

左栏提供段落、代码、资源、主题、快捷键、拼写与配对。表格、脚注、YAML 使用范围事务；浮栏与人工历史协作。图片可粘贴、文件拖入、缩放、发布相对资源，上传必须明确执行。

公式、图表和媒体按需加载；本地音视频支持有界流和 seek。导出依据完整正文，不依赖滚动截图。复杂语法与主题边界见[能力矩阵](../editing/refactor.md)。

## 导航与材质

导航按文件名、网页域名、公式及按钮内容测量。短内容收紧，网址保留至少20字符宽度，长公式尽量占用可用空间；长标题省略，输入框不因尺寸变化丢失草稿。

宽度与位置共用可中断弹簧，逐帧直接写样式，运动中复用玻璃纹理；停稳后精确更新。无选区时浮栏不订阅无关导航几何。

拖选结束后才显示选区工具。按钮提示框归属触发它的浮层，不触发该浮层避让自身；其他悬浮框仍参与碰撞处理。几何观察合并到一帧，边界未改变时不重启位置运动。

碰撞通知复用已测量的边界，不再反馈触发全量测量；嵌套浮层共享父几何。弹簧每帧只写最终位置，静止时不重复写样式；原生按钮提示只在窗口原点纠正时测量。正文变化只检查新增的材质子树。

浮栏先显示按钮和低成本表面，点击不等待纹理或动画。光学纹理由 worker 生成，繁忙时保持同布局 CSS 表面。深色磨砂无内部白色高光，保留模糊、底色、外投影与焦点。支持减少动态效果、降低透明度及关闭玻璃。

## 其他格式

Office 使用原生画布，明确区分对象和内部文字。PDF 使用画布与文字层，提取和 OCR 须报告页面与来源；覆盖标记不删除底层正文。

网页在独立 Chromium 视图运行。语义元素引用绑定 frame/导航/DOM 世代；坐标输入另外依赖布局及可见宿主。读取的网页与文档内容属于不可信数据，不能授予工具权限。

语义操作仅确保后台页面已加载，不附带重复的正文提取。网页内容通过明确读取取得，导航后旧引用失效。

Agent 后台操作不改变人工焦点；显式视图操作才激活、定位、复制或关闭页面。正文缩放与导航尺寸分离，每视图独立保留位置、模式和选择。
