# 阅读与交互

面向横版桌面。主页管理最近文档、示例和译文；新标签页搜索接受文件名、本地路径和网址。异步打开替换发起请求的新标签，不抢走用户随后选中的页面。Ctrl+L 聚焦地址/搜索，Ctrl+, 打开设置。

## Markdown

阅读模式可直接编辑并隐藏非活动标记；源码模式保留标记；分栏提供只读虚拟预览。三种模式共享源码、历史和 UTF-16 范围。分栏直接消费编辑器的不可变 Text/ChangeSet，显示与选区不等待 Core 回执。无法精确定位的选区不提供写操作。

左栏提供格式、代码语言、资源、主题、快捷键、拼写及配对设置；表格、脚注和 YAML 可视编辑写回源码。浮栏格式操作进入同一人工历史，回流安装期间的 Undo/Redo 按顺序重放，避免快速撤销失效。切换、关闭、导出和文件操作先排空草稿；未保存文件拒绝改名、移动和回收。

Ctrl+P 快速打开，Ctrl+Shift+F 搜索工作区全文，文件树按需展开。支持新建、移动、回收和撤销，遇到外部修改拒绝覆盖。图片支持真实文件粘贴/拖入、缩放、保存后相对路径及显式上传；配置或粘贴不会自动执行上传命令。

公式、图表和本地音视频按需加载；媒体支持 Range 和 seek。HTML、PDF、分页 PNG 基于完整源码导出；随包 Pandoc 提供 DOCX、ODT、RTF、EPUB 和 LaTeX 转换。完整能力与复杂语法边界见[编辑矩阵](../editing/refactor.md)，不据代表性样本承诺完全等同 Typora。

## 其他格式与工具

每个视图独立保存位置、选区、缩放和模式。正文缩放不改变导航和侧栏尺寸，背景设置不写入文件页面。PDF 使用真实画布和文字层，OCR 标明页及识别来源。[Office](../office/README.md)使用原生引擎，分别处理对象与内部文字选区。

选区工具先显示按钮和轻量表面；交互不等待纹理、背景采样或动画。折射纹理在 Worker/OffscreenCanvas 生成；繁忙或不支持时使用同布局 CSS 表面。合并几何测量，尊重减少动态效果、降低透明度和关闭玻璃设置。

网页位于独立 Chromium WebContentsView。输入坐标使用 CSS 像素并核对 navigationId/layoutRevision，截图像素不能直接作为点击坐标。本地 HTML 副本净化脚本和敏感表单值，外部资源仍可能联网；当前页面读取不代表完整跨 frame 或离线归档。

实际验收范围见[测试](../../tests/README.md)，延迟及大文件限制见[性能](../performance/README.md)。真实 Windows 拼音输入法仍需解锁后的交互桌面验收。
