# Office 左侧工具箱完整需求

**这是需求设计，包含尚未实现的功能，不代表下表全部已经接入。** 日期：2026-10-12。布局、导航和工具分组按编辑任务重新建模；现有代码仅用于标注可复用命令，不作为设计边界。本附件覆盖 Word、PPT、Excel 及旧 Office 转换后的编辑，供跨格式左栏总设计引用。默认只考虑横版桌面窗口。

## 1. 左侧工具箱需要解决的任务

| 格式 | 用户的主要任务 | 左栏默认内容 | 编辑时需要持续可见的信息 |
| --- | --- | --- | --- |
| Word | 理解长文结构、统一样式、调整页面、编辑表格/图片、完成审阅 | 结构树与搜索，按标题/页面/对象切换 | 当前作用范围、样式继承、章节/页位置、保护状态 |
| PPT | 浏览和重排页面、选择叠放对象、统一版式、编辑内容、准备演示 | **真实页面缩略图**、页号、分节及当前页状态 | 当前页、选择的对象/组、层级、母版来源、溢出警告 |
| Excel | 定位工作表/范围、编辑值与公式、整理数据、分析与打印 | 工作表、命名范围、表/图表/透视表对象目录 | 选区地址、单元格类型、原始公式、计算状态、筛选范围 |

Word 官方导航包含标题、页面与搜索，也允许重组标题；表格、文本框和页眉页脚内的标题不出现在该导航列表。本项目需另外提供对象树，覆盖这些区域。LibreOffice Navigator 的导航对象更广，可作为结构模型参照。[Word 导航](https://support.microsoft.com/en-us/word/use-the-navigation-pane-in-word)、[LibreOffice Navigator](https://help.libreoffice.org/latest/en-US/text/shared/01/navigator.html)

PPT 普通编辑视图、页排序、备注、大纲与母版服务不同任务；对象选择窗格还提供叠放顺序、显示/隐藏、分组与命名。左栏必须同时支持页面层级和页内对象层级。[PowerPoint 任务视图](https://support.microsoft.com/en-us/powerpoint/training/choose-the-right-view-for-the-task-in-powerpoint?ad=us&rs=en-us&ui=en-us)、[对象选择窗格](https://support.microsoft.com/en-us/powerpoint/use-the-selection-pane-to-manage-objects-in-documents)

Calc 的数据工具包含排序、筛选、透视、有效性、计算与分组；函数向导还提供参数输入、引用选择和公式结构检查。因此 Excel 工具箱要有范围和公式对象，不能停留在单元格字号/填充操作。[Calc 数据工具](https://help.libreoffice.org/latest/en-US/text/scalc/main0112.html)、[函数向导](https://help.libreoffice.org/latest/en-US/text/scalc/01/04060000.html)

以下矩阵与交互规则是根据任务推导的项目需求，官方资料用于界定基准功能；具体面板组织、命令名和验收样例属于本项目设计。

## 2. 共同面板行为

### 2.1 面板组织

左栏承载三类工作内容：**导航、工具箱、审阅/检查**。这是任务模型，不要求额外增加三套标签。可见分类遵循[左侧工具栏总设计](./LEFT_TOOLBOX_REQUIREMENTS_2026-10-12.md)：每种格式最多 7 个主要入口，其余进入“更多”或当前对象的次级工具；矩阵的每一行不直接对应一个常驻图标。

- 导航提供结构树、真实页预览、范围目录和搜索结果。导航操作只改变视图位置，不改变文件。
- 工具箱提供可搜索的功能目录及当前对象属性。常用工具直接显示，复杂命令展开参数表单；搜索同时匹配中文名称、用途和 command ID。
- 审阅/检查集中呈现批注、修订、对象溢出、错误公式和保真报告。结果点击后回到实际对象。
- PPT 页预览是页面导航的唯一列表，可与当前页工具通过可调分隔区并存。切换对象属性时保留当前页缩略图及选页状态；不再生成另一套重复页列表。
- 左栏宽度可调整并按格式记忆；窄宽度保留入口和当前目标摘要，长标签显示提示。收起后仍能通过快捷键/命令搜索打开工具。
- 面板展开、切换、收起不得使顶栏消失、增加外围正文框体、改变文档缩放或提交编辑。

### 2.2 目标与参数表单

| 状态 | 必须提供的行为 |
| --- | --- |
| 无选区 | 显示可插入的对象与文档/页面任务；格式命令要说明作用于插入点、当前段落或当前页 |
| 单目标 | 展示实际属性、单位与来源；Word 显示直接格式/样式继承，PPT 显示本页/母版，Excel 显示值/公式/格式 |
| 多目标或混合值 | 显示“混合”，不得用第一个对象的值伪装为全部一致；仅写入用户明确更改的属性 |
| 表格/分组对象 | 提供“对象本身/内部内容”的目标切换；不能把整个表或组当成普通文本块改写 |
| 参数正在编辑 | 表单拥有自己的草稿；轮询和 Agent 更新不得覆盖未提交参数；失去焦点不能执行危险结构修改 |
| 目标发生变化 | 参数卡片仍绑定原目标；提示目标已变化，并提供重新选择或取消，不随当前标签漂移 |
| 受保护或引擎不支持 | 显示原因及可用替代路径；禁用真实不支持的命令，保留其说明，不提供看似成功的空操作 |

枚举与布尔设置可直接应用并形成事务；字号、边距等数字在有效提交时应用，连续拖动应合成一个可撤销事务。页序重排、删除、排序、批量替换和母版应用要明确范围及受影响数量。预览只影响临时视图，取消后模型与文件字节不变。不能无限缩小字体来掩盖溢出。

选择文字后，轻量格式仍可从选区浮窗执行；浮窗与左栏调用同一 command 和同一选区快照。用户在左栏输入参数时，正文高亮可以保留，但不能抢回键盘焦点。Agent 的目标高亮与操作说明反映实际事务，不进入文档、缩略图或导出。

### 2.3 矩阵标记

- **现**：当前 schema 已有的命令，可作为后端复用起点；仍需按文件能力判断。
- **拟**：本设计新增 command，尚未实现；命名需在统一注册表定稿。
- **完整引擎**：需要完整 Writer/Impress/Calc 模型、排版或计算能力；现有 OOXML/ExcelJS 补丁不等价。
- **读/视图**：导航、查询或预览，不写文件；同样应给 harness 提供语义接口。

所有编辑行均遵循第 6 节的共同 MCP 桥。矩阵“验收”列给出该行必须补充的专项场景；另须通过第 8 节的共同保存、撤销和并发验收。

## 3. Word：结构、样式与版面工具箱

### 3.1 功能目录与上下文

导航目录需包含标题、节、真实页面、表格、图片/框架、书签、字段、脚注/尾注、页眉页脚、批注与修订。按类别筛选并允许跳转到隐藏/受保护对象的可阅读位置。标题拖动要明确“仅标题”与“整个章节”的区别。

工具箱分为文字、段落/列表、样式、页面/分节、表格、对象、引用、审阅。六类 Writer 样式——字符、段落、框架、页面、列表、表格——说明样式不能缩减为几个标题按钮；页面设置也包含页眉页脚及奇偶/首页规则。[Writer 样式](https://help.libreoffice.org/latest/en-US/text/swriter/01/05130000.html)、[Writer 页面属性](https://help.libreoffice.org/latest/en-US/text/swriter/01/page.html)

## 4. PPT：真实页预览、对象与演示工具箱

### 4.1 页预览是必选能力

左侧必须显示**真实渲染的每页缩略图**，包括图片、对象、文字、背景与母版。文字摘要可附在图下，但不能代替页面预览。缩略图按原比例显示，页号与页面标题在图外呈现，标记当前页、多选、隐藏页、备注/动画存在、未保存及渲染失败。

LibreOffice 页排序通过缩略图重排；母版决定标题/大纲样式与背景，切换效果包含时长、声音和手动/自动推进。因此页预览、普通页编辑、母版编辑、动画预览必须保持不同的模型范围。[Impress 页排序](https://help.libreoffice.org/latest/en-US/text/simpress/01/03100000.html)、[Impress 母版](https://help.libreoffice.org/latest/en-US/text/simpress/guide/masterpage.html)、[Impress 切换效果](https://help.libreoffice.org/latest/en-US/text/simpress/01/06040000.html)

页预览具体要求：

1. 支持点击定位、Ctrl 多选、Shift 范围选、键盘导航、页号搜索、分节折叠及拖动重排；拖动在松开前只展示插入位置，松开后提交一次页序事务。
2. 当前页与临近页优先生成；长文稿虚拟化列表和懒加载，避免一次渲染全部页面。用户可放大缩略图查看细节。
3. 缓存键包含文档、稳定 slide ID、内容/布局版本、主题/字体环境及尺寸；旧请求不能覆盖新版本。页面删除/移动后 ID 保持语义一致。
4. 图像来自当前未保存的权威编辑模型；不能偷偷先保存覆盖原文件。只支持静态导出时标明“静态预览”，动画/媒体需专门播放视图。
5. 失败时显示占位、原因与重试；母版/字体/媒体覆盖不足需报告，不能把空白或摘要标为完整页图。

## 5. Excel：范围、公式与数据工具箱

### 5.1 功能目录与上下文

工作簿树显示工作表、命名范围、表对象、图表、透视表、批注、外部数据源及打印区域，允许按名称/对象类型搜索。对象卡片可锁定具体范围，滚动或点击其他格不会静默改变正在配置的排序、验证或图表源。

## 6. 所有编辑功能共用 MCP 桥

### 6.1 一个语义注册表

每个功能定义一个 `CommandDefinition`：command ID、参数 schema、读/视图/编辑/产物效果、适用格式/对象、引擎条件、作用范围、单位、混合值表达、预览、撤销与保真限制。左栏、选区浮窗、快捷键、命令搜索和 MCP 都查询该注册表并调用相同处理器。不能出现 GUI 有功能、harness 只能点击图标的孤立实现。

| 阶段 | 当前可复用接口 | 本设计要求 |
| --- | --- | --- |
| 发现 | `document_capabilities` | 增加按目标查询状态/原因及 schema 版本；矩阵拟定命令接入前不能报告 available |
| 读取 | `workspace_list`、`document_read/outline/search`、`reader_get_context/selection` | 分页查询对象/属性/依赖/真实页面；现有基础投影不能替代完整 Office 模型 |
| 预览 | `document_plan_patch` | 返回目标清单、范围、实际影响、格式风险；新增批次 schema 与 batch 原子性声明 |
| 提交 | `document_apply_patch` | 同一权威引擎会话，固定目标、前置版本和幂等；禁止执行未经注册的任意脚本/UNO 字符串 |
| 导航/缩略图 | 当前视图管理与缩放；对象导航/预览拟扩展 | 返回稳定锚点、当前版本、预览资源 ID；大图片通过资源/产物按需取，不全量塞进 state |
| 历史 | `document_undo` | 保留当前“无后续修改”条件；目标级逆操作/redo 是新增能力，需验证其条件 |
| 保存/导出 | `document_save`；导出拟扩展 | 文件摘要冲突、原子落盘、固定源版本、可读取产物、覆盖与格式损失清单 |

公开工具族与总设计第 11 节一致：拟新增 `document_list_commands/get_command`、`document_list_objects/get_properties`、`reader_resolve_target/select_targets`、`document_prepare_command/commit_command`、history/export/job 等接口。现有 `document_plan_patch → document_apply_patch` 保留兼容，均进入同一注册表与事务层。矩阵中的“拟”名称是语义 command/operation 的候选 ID，不是当前可调用 MCP 工具，也不要求每个按钮新增一个 MCP tool。

### 6.2 稳定对象定位

| 格式 | 目标模型 | 必须解决的变化 |
| --- | --- | --- |
| Word | story/区域、稳定段落/字符范围、section/table/row/cell/object/field/comment ID | 插段后索引变化、表格网格变化、重分页、修订隐藏文字；不能以“第7段”或相同文字猜目标 |
| PPT | 稳定 slide ID、页内 shape ID、完整组路径、master/layout/animation ID | 页重排/复制后页号与对象身份分离；组内同名对象不能混淆；母版引用保持 |
| Excel | 稳定 sheet ID、语义 range anchor、行列映射、name/table/chart/pivot ID | 表改名、插删/移动行列、排序、表扩展；A1 坐标要与锚点版本一起解释 |

可利用 OOXML 既有标识及引擎对象句柄，但应用还需维护跨操作映射和 `engineEpoch`。缺少可持续 ID 时用应用侧映射；重开后无法可靠关联要返回失效，不能给新对象复用旧锚点。文字、公式或对象属性摘要可作为前置条件，但相同文本/相同数值不是唯一身份。

页面号、列表 index、屏幕坐标均是读取投影。API 同时返回稳定目标与可读位置；鼠标定位另带布局/导航版本，文字范围另带选区身份与原文字检查。当前 slide 移动 0-based、行列 1-based、PPT 归一化 bounds 的兼容规则需在 schema 中明确，界面显示不暴露混杂索引。

### 6.3 版本、草稿与撤销

编辑请求绑定 `documentId/viewId/engineEpoch`、内容 revision、目标集合及前置条件，plan 后目标改变必须重新准备。批量编辑要明确 all-or-nothing 或可恢复阶段，失败不能悄悄部分成功。重连与幂等重试不重复插入页、行列、批注或对象。

用户参数草稿、正文输入与 IME 受保护。已有 `before-agent-edit` 会在存在未提交人类输入时拒绝 Agent 修改，不能替人类强制提交；未来可将文档级保护细化到已证明安全的目标租约。用户自发保存/切页使用输入同步屏障。Agent 固定目标不随用户切页变化，不能因左栏当前对象改变扩大作用范围。

正常编辑历史由同一引擎提供；Agent 撤销带原事务及目标当前条件，不能整文覆盖用户后来的编辑。现有条件撤销只能在无后续 revision 时执行，不应在界面表示为已经支持任意历史回退。导出/渲染与模型读取也须基于同一固定版本，预览与实际提交不可各读一份不同内容。

## 7. 实现与分期边界

### 7.1 权威模型和内置引擎

当前 OOXML/ExcelJS 命令可先接入新注册表，用于已有基础文字、段落、页面参数、页序、对象和单元格结构操作。现有内置 LibreOffice 入口是独立编辑窗口，工作台尚不是完整内嵌 Office 会话；不能据此外推矩阵中的实时分页、样式体系、母版、图表、媒体/动画、审阅、计算及复杂数据结构已经支持。上述能力需要完整引擎接入，不能用拼 XML、文字覆盖、截图替换或 CSS 预览改变冒充。

Office 每文档只有一个权威 writer。接入完整引擎后，UI 与 harness 走同一会话，不能让 OOXML writer 和独立 LibreOffice 窗口同时改同一文件。引擎/字体/转换资源随应用提供，主线不能要求用户安装 Office、Docker、WSL 或外部编辑服务器。Windows 原生 host、实时 viewport/selection、进程隔离与桥接验证沿用[完整编辑规划](./EDITING_CAPABILITIES_PLAN_2026-10-12.md)。本附件不宣称该完整 host 已验收。

旧 `.doc/.ppt/.xls` 先明确转换为现代编辑副本，保留原件及转换报告。文件含宏、保护、签名、外部关系或当前引擎不支持的扩展时，能力判断需按该文件返回；不能通过另存 `.docx/.pptx/.xlsx` 静默丢弃这些部件。VBA 运行、云协同、专有 Designer/数据连接提供商不作为首轮必需功能；已有内容须保留或明确拒绝写入。

### 7.2 实施优先级

| 阶段 | 交付目标 | 进入下一阶段的条件 |
| --- | --- | --- |
| P0：统一工具箱与现有命令 | 三格式独立任务目录、目标/混合值、参数草稿、能力发现、同一 MCP 桥；PPT 真实静态缩略图与页管理；Excel 值/公式身份、格式/结构与计算状态 | 全部可用按钮有真实 handler、UI/MCP同结果、失败保留、保存重开及条件撤销通过 |
| P1：完整生产编辑 | Word 分页/样式/表格/对象/引用/审阅；PPT 母版/布局/对象树/动画媒体；Excel 计算/名称/验证/条件格式/表/多条件筛选排序/图表透视 | 完整引擎在本机内置模式可运行，实际 viewport/selection与保存会话一致；复杂包样本验收 |
| P2：高级工作流 | 多文档模板/批量处理、对比/引用库、演讲者/讲义、外部数据与高级分析、目标级历史 | 冻结任务、资源管理、并发/恢复与格式损失报告成熟；外部能力按用户明确配置开放 |

P0 先做到完整、可发现的工具架构和现有能力闭环；不把所有 P1 项显示为可点击但没有效果的按钮。完整编辑承诺以各功能的验收记录与实际引擎能力为准。

## 8. 共同验收门槛

1. **GUI/MCP 一致**：每个编辑 command 用同一原件分别从左栏与 MCP 执行，语义、保存产物、目标和警告一致；无 GUI 专用编辑接口遗漏。
2. **真文件闭环**：操作后保存、关闭、重新打开；检查结构和引用，并使用实际 Office 引擎渲染/计算复核。只验证 ZIP 文字或 DOM 外观不足以通过复杂功能。
3. **目标保护**：plan 后插段、重排页、改表名或插列，过期目标不能误编辑邻居；重复文字、同名对象和相同单元格值均不混淆。
4. **草稿/并发**：正文和参数表单输入、IME、正在提交以及 Agent 更新互不覆盖；关闭/切页失败保留稿；Agent 修改冲突有明确目标与原因。
5. **多对象事务**：批量格式、页面重排、列表/表格结构、排序等一次合理事务；取消/失败不留半完成产物；撤销条件与不能撤销的效果明确。
6. **PPT 页预览**：图片、字体、母版、背景、备注/隐藏标识、页重排、未保存编辑与渲染失败分别验收；延迟旧图不能覆盖最新内容。
7. **公式与数据**：真实计算、缓存状态、日期体系、中文表名、跨表/命名/结构化引用、动态数组、筛选排序及验证；未支持的类别明确拒绝。
8. **长文/大表**：长结构树、千页缩略图和大范围查询分页/虚拟化，正文轮询不重建整个工具箱；关闭/停止任务释放资源，缓存清理不删除原件/正式产物。
9. **桌面可用性**：1280×800、1440×900、1920×1080，Windows 100%/150%/200%，键盘、读屏、减少动效与透明度下目标和命中一致；面板变化不影响顶栏/正文容器。
10. **能力诚实**：受保护、缺字体、未覆盖对象、旧格式转换与导出损失有具体范围报告；没有实际成功的功能不返回完整成功，不以“已保存”掩盖内容丢失。

本轮只输出需求附件，没有修改源代码、现有布局或引擎，也没有执行 UI、构建、安装与发布。
