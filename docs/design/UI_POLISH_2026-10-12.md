## 1. 功能与材质

| 部件 | 本轮行为 |
|---|---|
| 悬浮提示 | 始终使用磨砂玻璃、对应浅／深色文字，无黑色 fallback 切换。Native 提示与普通提示共用退出计时；不生成光学地图。 |
| Word／PPT／Excel | 原顶部编辑 ribbon 移到左栏。首次打开默认展开对应格式工具；本次运行内不同文档分别记住面板和收起状态。导航只保留通用导航、模式、缩放、撤销和保存。 |
| 导航／Agent 胶囊 | 统一尺寸与光学参数，实际正文采样、边缘折射与高光。Agent 保持真实目标和事件位置，不给鼠标轨迹增加偏移。 |
| AI 结果／选区译文 | 小浮窗采用完整折射，右侧大抽屉保持磨砂。原生网页使用可信独立视图，正文采样复用既有单在途／缓存／增量传输管线。隐藏后停止采样。 |
| 普通界面 | 侧栏、设置、主页、选区快捷条等保留轻量磨砂。透明采样祖先不做整体 opacity 动画，以免光学内容变黑。 |

玻璃机制唯一参考为 [kube.io 文章与示例](https://kube.io/blog/liquid-glass-css-svg/#searchbox)。凸 squircle、Snell 折射、高光及弹性分别建模；项目做共享几何与桌面交互适配，未安装另一套玻璃技能覆盖参数。

| 参数 | 导航 | Agent 操作胶囊 |
|---|---:|---:|
| 高度／圆角 | 60／30px | 42／21px |
| bezel／厚度 | 29／70px | 20／70px |
| 折射率／强度 | 1.5／0.82 | 1.5／0.82 |
| 高斯 blur | 1px | 1px |
| 高光 opacity／saturation | 0.24／4 | 0.24／4 |
| 采样 overscan | 30px，包含 20px 收起轨迹包络 | 29px |

采样几何来自实际 CSS 尺寸和像素密度。Native 浮窗外部透明，不存在整行矩形遮罩。AI 结果固定显示高度，流式文字在内部滚动，避免每次 token 改变光学地图尺寸。Native 根据实际正文样本亮度选择文字和 tint，适配深色应用中的浅色网页。

## 2. 右侧 AI 工具和 MCP

工具分为理解、分析和学习，共 11 项：摘要、解释片段、术语释义、关键点、证据摘录、内容大纲、论点审查、公式解释、表格分析、阅读问答、学习卡片。详细官方功能参考、提示和限制见[AI 阅读工具](AI_READING_TOOLS_2026-10-12.md)。

UI、HTTP `ai-reading-tools / ai-reading-run`、MCP `reader_ai_tools / reader_ai_run` 共用目录和执行函数。调用指定 `viewId`、`toolId`、`scope`，可绑定冻结 `snapshotId`，并提供幂等键。范围为选区或当前可见材料；全文、多文件和联网任务需要以后单独接入。空选区、未知范围、未就绪／版本错配和超过 48,000 字符输入均明确拒绝，不静默扩大范围。

结果显示来源范围和版本，可复制、取消，或打开为新的 Markdown 文档后保存。阅读分析幂等记录位于当前进程内，最多保留 256 项，只淘汰已结束任务；在途请求不淘汰。重启或记录淘汰后不承诺同键复用，调用方应先查询原任务，而非将跨重启重试当作持久幂等。分析不写原文；选区译文独立显示，网页翻译仍按原地恢复协议执行。自然语言引用尚未经过逐字锚点校验，因此不伪装成可验证的跳转按钮。确定性表格计算、复习排程、复杂图表视觉理解和多文档比较仍在后续接口中。

## 3. 优雅动画

外观设置新增“优雅”。普通过渡略放慢；优雅按原时长乘 2.6 并限制在 420–650ms，侧栏 572ms，弹窗／Agent 胶囊 520ms。减少、关闭动效和系统减少动态效果继续优先生效；键盘焦点相关开关立即完成。

优雅按压缩放 0.975，弹簧阻尼比 0.78。拖动直接跟手，释放继承速度并回弹；途中重新抓取使用当前呈现状态。展开／收起保留退出节点，可中途反向；使用 transform 和前景／光学叶子渐隐，避免高度插值或整个采样祖先半透明。关闭动效会立即取消活动 RAF 并清理临时 will-change。
