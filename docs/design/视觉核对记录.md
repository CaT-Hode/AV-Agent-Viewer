2026-10-09。参照 `workbench-concept.png`，最终实现 `workbench-implemented.png`；同一轮使用 view_image 检查二者。参照与桌面截图均为 1586×992；桌面 DPR 1.5，截图按 CSS 尺寸输出。IAB 实际 DOM 视口另检查为 1442×902，工具面板截图范围受面板限制，因此最终布局证据使用实际桌面截图。

| 比较点 | 参照 | 实现与修正 |
| --- | --- | --- |
| 三栏布局 | 左侧约 297、右侧约 396，中央约 893；标签/地址与阅读工具分行 | 修正原先过窄侧栏；桌面宽度使用 clamp，参照尺寸达到相同列宽。没有卡片式外壳或移动布局 |
| 首屏层次 | 欢迎标题、说明、紫色引用、共同阅读、编辑与保存、表格 | 保留顺序、文字区左右约 80px 内距；标题修正为 44px，正文 17px/1.75，章节标题 32px |
| 配色与容器 | 白色正文/右栏、浅冷灰 chrome、紫色活动态与左边引用线 | 使用 #fff、#f5f6f9 与 #7263e8；保留细边框、开放内容区，不叠加背景渐变或 raster UI |
| 图标和控件 | 线性导航/文件/位置图标、Office 格式色块 | Lucide 线条、Word/PPT/Excel 小色块；真实点击/禁用状态。保留较紧凑的 13px 主要操作按钮，适应多标签编辑工作流 |
| 上下文面板 | 位置、选区、Harness、底部提问框 | 真实位置与选区填充，未连接状态；空问题“发送”禁用。提问框调整到参照的底部位置和高度 |
| 资产与真实状态 | 参照为一张完整工作台概念图 | 界面全部为原生组件，不把图当 UI；显示当前文件、活动标签、保存/连接状态，不填虚构任务或假位置 |

## 首屏文案差异

| 差异 | 处理理由 |
| --- | --- |
| 地址栏由“欢迎.md”显示实际完整路径；网页标签显示真实站点标题 | 满足来源定位和浏览器式导航；不是新增宣传文案 |
| 大纲“入门”改为实际标题“欢迎使用 AgentViewer”，增加正文已有的“开始使用” | 大纲从真实 Markdown 生成，避免与正文结构不一致 |
| “更高效”改为“可追溯”；阅读位置/选择/快照三条说明以实际状态语义表述 | 对齐可见区域、原文定位和不可变问题快照，减少未验证的效果陈述 |
| 编辑说明改为“源码模式可编辑本文；Office/PDF 按当前引擎能力提供基础编辑” | 参照的笼统完整支持表述超出首轮实现，必须展示真实范围 |
| PDF 表格“批注与页面”改为“文字增补与页面” | 本轮高亮是页面覆盖，原生批注尚未集成 |
| 增加“复制视图/新窗口”和撤销图标；100% 使用静态标记 | 多开与撤销是实际功能。缩放菜单没有实现，避免画出假控件 |
| 上下文位置与标签由运行状态决定；“发送”按问题内容禁用 | 截图在位置已确认后采集，不固定虚构当前章节或连接状态 |

核对确认主内容、标题、导航和侧栏没有被裁切；长文滚动是阅读区行为。字体使用本机 Segoe UI/Microsoft YaHei，与生成图的栅格字形有细微差异。复杂 Office 预览精度单独列在实施状态，不通过截图外观推断文件保真。
