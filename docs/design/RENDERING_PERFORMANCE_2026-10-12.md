# 阅读器渲染性能修复

日期：2026-10-12；范围：减少重复编码、传输与正文执行，保留真实阅读位置、选区和材质参数。

> 后续控件要求：布尔／文字分段／范围开关与按需材质预览也使用完整折射，普通面板仍为磨砂。文字分段的上层镜片采样真实标签，光学资产继续共享缓存；关闭预览不挂载透镜。本文下方 CGYT9Dg5 性能证据属于前一轮，最终控件、提示与性能回归见[最新修复](SWITCH_TOOLTIP_REPAIR_2026-10-12.md)。

最新网页管线已由每次截图改为共享实际呈现帧：每页一个完整帧订阅，各宿主只裁切小区域，保留 400ms 真实截图兜底和静态编码复用。完整折射的 Gaussian blur 统一为 0px；普通磨砂独立保留。跨显示密度裁切采用物理像素对齐的实际 DIP 区域，网页 zoom 不作为显示密度。当前 Electron 正常窗口订阅上限为 30Hz，最终业务管线验收见上述最新修复文档。

## 已实现

- 原生网页采样原本已有单在途与最新待采样，但相同 bitmap 仍会重复 PNG 编码和发送完整图片。现在比较实际像素并复用编码，状态元数据与图片分开传输；滚动、正文变化、导航和尺寸变化仍使样本失效。
- 光学资产缓存由 24 项 FIFO 改为 LRU，最多 64 项，分别限制编码资产 8 MiB、估算解码资产 64 MiB。禁用玻璃时不生成地图；无变化的尺寸与材质不重复生成。64 MiB 只是缓存解码估计，不是 Chromium、SVG 或 GPU 的总占用上限。
- App 对 workspace 与译文任务执行完整字段 structural sharing，无变化时不替换根状态，有变化时复用未改变的模型和数组。`capturedAt/viewRevision`、选区、视口、公式缓存、任务输出及新增字段仍参与比较，650ms 轮询不变。
- Office 正文与单元格使用稳定回调和 memo 边界，真实上下文更新不要求重新执行未变化的正文；实际编辑与选择变化继续更新对应目标。
- 普通组件默认 `effect="frosted"`，不订阅几何观察器、不生成折射地图或 PNG、不挂 SVG 滤镜；只保留 CSS 磨砂、tint 和交互动画。最新需求在导航与 Agent 胶囊之外，也启用 AI 结果／选区译文小浮窗折射。原生网页的 Agent 与 AI 结果复用可信 host／采样缓存／图片增量管线，各自仅保存当前小区域；隐藏后停止对应采样。
