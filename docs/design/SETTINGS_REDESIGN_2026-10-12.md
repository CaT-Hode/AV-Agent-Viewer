# 独立设置窗口改造

> 最新控件修复：布尔开关缩至约 68×28px，分段轨道／滑块为 36／28px；布尔、多选、范围滑块和按需材质预览恢复完整折射，其他设置保持磨砂。本文旧 96×40.2／44px 控件与“全部设置磨砂”的描述为前一轮记录，当前验收见[开关与提示修复](SWITCH_TOOLTIP_REPAIR_2026-10-12.md)。

日期：2026-10-12；状态：阅读交互、设置组件与渲染性能已通过本轮真实 Electron 回归，最终 Office/启动/安装状态由主线补录。仅针对横版桌面窗口。

## 布局与控件

设置保留独立、非模态窗口，采用 Apple 风格的分组层级：左侧分类与图标，右侧标题、搜索和分组卡片；设置说明与控件分开排列，ID、生效时机等信息按需展开。尚未接入的选项集中在折叠区，仍显示真实依赖原因并禁用。

布尔值使用可点击、横向拖动的 `GlassSwitch`；枚举使用 `GlassSegmentedControl`，透明光学滑块位于文字上方，可横向拖动并落在最近选项，也支持点击和键盘方向键。布局宽度、隐藏等待时间使用 `GlassRangeControl`。这些控件和按需材质预览使用完整折射，普通设置面板、输入与搜索保留磨砂；静止光学地图共享缓存，不随交互位置逐帧重建。减少动效、关闭动效及系统减少动态偏好保持有效，减少透明度时移除文字上方的光学层。

设置行采用紧凑尺寸并右对齐：布尔开关按作者内部 160×67 几何等比适配，原生 CSS 尺寸约 **68×28.475px**，不用 CSS zoom；枚举轨道高 **36px**，滑块高度随真实边框与容器尺寸计算。深色带文字分段采用绿色选中底与白色文字，颜色底板位于文字下方，透明折射镜片位于文字上方。上述尺寸取代旧 96×40.2／44px 记录。

玻璃材质示例只在“外观与布局”的“预览玻璃材质”中按需展开，不占据常规设置页面。示例是可拖动磨砂卡片，已去掉透镜放大与折射；正文缩放由独立的 `view.zoom` 控制。

## 保存与撤销

普通偏好继续通过 `settings-set` 即时保存，并广播到其他窗口。页面只接受不低于当前 revision 的快照，避免较晚返回的旧响应恢复旧值。设置 revision 随每次更新递增，撤销也是一次新更新。

顶部只保留全局“撤销上一次设置更改”，不为每个选项增加撤回按钮，也不显示“仅显示已修改”筛选。撤销作用于本次运行的设置历史，最近 100 次；模型连接、凭据等组合配置保留原来的局部保存流程，不混入偏好撤销。

## 接口与边界

设置定义、ID、默认值、可用性校验、版本化 JSON 和跨窗口通知仍由 `SettingsRegistry/SettingsService` 管理。文档结构编辑、文件保存与冲突校验、模型发现/连接/工具路由、运行任务固定配置均沿用原接口；此次改造不改变文档身份、文件格式或 MCP operation schema。

主要入口为 `SettingsApp`、`SettingsGroups`、`GlassControls`、`GlassSegmentedControl` 和 `packages/settings`。已记录后端联合回归 35 项通过；阅读交互和设置组件已完成真实 Electron 验收，性能证据见[渲染性能修复](./RENDERING_PERFORMANCE_2026-10-12.md)。最终 Office memo 回归、启动与安装状态继续由主线记录。
