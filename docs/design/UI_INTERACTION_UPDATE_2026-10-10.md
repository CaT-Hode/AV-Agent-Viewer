# 2026-10-10 交互与玻璃材质更新

## 设计方向

低饱和蓝青环境色、石墨深色底、细腻的边缘反光。标志性交互是正文上方的单行悬浮胶囊：向下滚动让出正文，向上滚动或聚焦时出现。正文不做入场、漂移或缩放动画。

参考并安装 liquid-glass-frontend 技能：https://github.com/ngocanhnckh/liquid-glass-frontend-skill 。材质采用三组品牌 RGB、浅深主题语义变量、30–42px 模糊、饱和度补偿、内侧反光与背景环境色。MIT 许可见 licenses/liquid-glass-frontend-MIT.txt。

## 材质与组件

- 导航、选区和 Agent 状态采用胶囊；侧栏采用悬浮圆角矩形。
- 选区工具始终单行、图标化；批注、替换与提问输入在下方独立面板展开。
- 侧栏与胶囊使用轻薄玻璃；正文结果、弹窗和输入面板使用较高遮盖率，保证小字清晰。
- 仅容器模糊，内部按钮使用透明色与内侧反光，不嵌套背景模糊。
- 网页使用可信原生浮层。仅对胶囊下方小块网页进行内存采样和模糊，400ms 更新一次；隐藏、最小化、关闭玻璃时停止采样。采样不落盘、不发送给模型。导航轮廓外裁切为透明，不增加整条遮罩。
- 浅深主题、增强玻璃、减少透明度、高对比度、减少动效均有回退。
- 白色 PDF / Office 页面上，选区胶囊使用深色图标。

## 动效选择

1. 胶囊隐藏/出现：160–200ms 透明度与小幅位移。
2. 临时抽屉、弹窗：220ms 小幅进入，不影响正文排版。
3. 点击：120ms、0.97 缩放。
4. 开关：160ms 滑动。
5. 提示：140ms 淡入；结果通知：180ms 小幅进入。

统一 cubic-bezier(.22,1,.36,1)。不采用正文滚动显现、持续漂移背景、标签切换动画或大范围视差，避免妨碍阅读与 Agent 坐标定位。

## 其他交互

左上角仅保留静态 Logo；加号建立新标签页，打开文件时消耗该空标签。重复点击左侧当前工具关闭面板。网页去除左侧工具。设置使用全局撤销，移除逐项箭头和仅显示已修改筛选。未保存文档关闭采用统一应用弹窗。工具提示统一为圆角深色浮窗。

## 选区工具和 harness

同一 selection-action 服务供 UI 与 MCP 调用，绑定快照、目标版本和幂等键。

| 格式 | 本轮接入能力 |
| --- | --- |
| Markdown | 复制、引用、摘录、批注、加粗/斜体/代码、精确替换 |
| DOCX | 文字范围格式、标题/对齐、替换；保存后保持其它 run |
| PPTX | 文字范围格式、替换、对象居中 |
| XLSX | 文字与单元格格式、填色、对齐、替换；保留公式 |
| PDF | 按文字逐行位置高亮/下划线/删除线，支持旋转页 |
| HTML | 安全单文本节点格式/替换、应用侧批注 |
| 网页 | 复制、引用、摘录、应用侧批注、原地翻译与提问 |

新增 reader_selection_tools、reader_selection_action、document_annotations、document_remove_annotation。AI 工具要求先配置连接。复杂 Office run 及不确定的 HTML 目标明确拒绝；PDF 标记属于覆盖标记，不是删除底层文字。批注与摘录来源单独保存，原文版本变化后标识失效；再次定位不是任意文档变化后的自动语义重定位。

## 验证范围

核心测试涵盖快照、持久化、幂等、Word/PPT run、Excel 公式、PDF 旋转页。Electron 界面测试覆盖主题/玻璃开关、全局设置撤销、滚动隐藏、原生网页位置、单行选区胶囊、实际编辑及关闭弹窗。选区测试还通过 stdio MCP 发现和调用新增工具。截图保存在 artifacts/ui-theme 和 artifacts/ui-selection。
