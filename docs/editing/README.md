# 文档编辑

## 格式能力

| 格式 | 当前实现与边界 |
| --- | --- |
| Markdown | CodeMirror 实时、源码、分栏；工具栏、可视表格、公式图表、链接、资源、文件工作区、偏好及导入导出；详见[对标矩阵](refactor.md) |
| HTML | 源码、净化预览、选区定位与保存；不是完整可视富文本编辑器 |
| DOCX | Writer 文字/段落/表格和页面命令；复杂排版需原文件验收 |
| XLSX | Calc 输入、公式、样式及工作表；完整范围使用原生查询，辅助投影有界 |
| PPTX | Impress 对象与内部文字、样式、缩略图及导出；母版和动画需样本验收 |
| PDF | OCR、增补文字、覆盖式标记、旋转与增页；不提供原文删除或安全涂黑 |

旧 `.doc/.xls/.ppt` 先转现代格式，保留原件。活跃 Office 使用原生模型，预览投影不能替代真实内容。

## 修改、撤销与保存

普通操作：读取能力和 revision → prepare → 检查预览 → commit 携幂等键 → 读回 → save。重试同次提交沿用同一键，内容变化重新准备。文本历史保存范围逆操作；原生撤销核对 token 与版本，不能覆盖后续编辑。

人工原生格式命令可先返回 applied；durability 为 pending 时仍未完成恢复检查点。dispatched 仅表示已派发，不能当作修改完成。保存确认冻结版本已写入源文件；恢复检查点不等于主动保存。

UTF-16 源范围贯穿编辑器、Core 与工具。组合输入期间协调本地草稿；远端非重叠修改可合并，重叠则保留草稿并显示冲突。切换、关闭、导出及资源批处理前排空草稿。

## Markdown 工作流

文件工作区按需展开目录，支持文件名快速打开、全文搜索、新建、重命名、移动、回收区及撤销。新建未保存文档先选择目录；文件变更受根目录约束。

图片可粘贴/拖入、调整尺寸及批量复制到本地、嵌入或上传。资源操作核对正文 revision；版本变化刷新后重新确认。上传只在显式点击时执行已配置命令。

未保存图片存入受预算约束的 profile 缓存，正文使用短引用；保存和另存时生成相对资源，保留代码示例中的原样引用。图片偏好、Typora 根目录与复制目录统一解析，资源访问不得越出授权目录。

偏好持久化主题 CSS、命令→快捷键、图片根目录、上传配置、导出模板。HTML/PDF/分页 PNG 使用完整文档导出路径；DOCX/ODT/RTF/EPUB/LaTeX 等转换需可选 Pandoc。配置与源码分别保存。

实时、源码和分栏共用增量语法；分栏右侧是只读虚拟预览，选区可映射回源码格式化，不拥有第二份编辑历史。字数统计针对源码，中日韩字符逐字计数，其他文字按词；字符数包含标记和空白。

浮栏写操作在调用前标记请求身份；仅精确对应提交版本且本地源码未变化的回流进入人工历史。Agent 回流不混入该记录，迟到、越版本或并发本地输入保留草稿并提示冲突。

超长单段落仍有边界：10 MiB 三模式的 beforeinput→下一 rAF P95 为 102–118 ms。复用保护已消除百万次 rope 逆向读取，但 DOM 差分与整行解析仍需重构；这不是所有输入或实际绘制的端到端指标。

本轮真实 Electron 已验证跨模式撤销、浮栏改动的键盘/侧栏撤销重做与顶部撤销、表格/脚注/YAML、分栏范围与防写、数学/三类图表。未保存图片粘贴后连续调整 50%→75%，live/分栏解码、HTML 导出及保存相对引用后重新解析通过；完整 PDF 逐页回读、PNG 总高与整文一致且无滚动条。真实 Windows IME、本地音视频、复杂语法和 Pandoc 转换仍待验；详见对标矩阵。
