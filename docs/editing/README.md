# 文档编辑

| 格式 | 当前能力 |
| --- | --- |
| Markdown | 实时、源码、只读虚拟分栏；表格、公式图表、资源、文件工作区、偏好及完整导出 |
| HTML | 源码、净化预览、选区定位与保存 |
| DOCX / XLSX / PPTX | 原生 Writer / Calc / Impress 编辑、属性、撤销、保存及独立导出 |
| PDF | OCR、增补文字、覆盖标记、旋转与增页；不删除原文或实施安全涂黑 |

旧Office先转现代格式并保留原件。活跃Office以原生模型为唯一写入源，辅助投影不反向覆盖原生内容。

## 修改与历史

读取能力和revision → prepare → 检查预览 → 携幂等键commit → 读回 → save。同次提交重试沿用原键，内容变化重新准备。文本历史保留范围逆操作；原生撤销核对会话、token和版本。

人工原生格式命令可返回applied，durability.pending说明恢复检查点尚未完成；dispatched仅表示派发。保存确认冻结版本已写源文件，恢复不替代主动保存。

UTF-16源范围贯穿编辑器、Core和工具。分栏直接消费源码CM的不可变Text/ChangeSet，保持真实Range；迟到Core回执不能覆盖新选区。浮栏人类格式回流只在身份、版本和未变化源码精确对应时进入CM历史；期间Undo/Redo按序暂存后重放。Agent回流不混入人工历史，冲突保留草稿。

切换、关闭、导出、文件操作和资源批处理均先排空草稿。文件改名、移动和回收拒绝未保存正文；回收可撤销，外部变化不盲目覆盖。

## Markdown资源与偏好

图片支持粘贴、真实文件拖入、尺寸、根目录、批量本地化、内嵌和显式上传。配置或粘贴不自动执行上传命令。未保存图片使用profile持久短引用，保存/另存后生成编码过的相对资源。

Typora根目录、复制目录和工作区授权根统一解析；读取真实路径并检查目录范围。本地音视频通过有界流协议播放，支持Range和seek，不把整段视频塞入IPC。普通媒体和单行HTML媒体均经过净化。

主题CSS、命令快捷键、拼写、配对、专注和打字机模式独立于正文。空快捷键会禁用继承默认键。源码字数按中日韩字符及其他词计数，字符数包含标记和空白。

HTML/PDF/分页PNG在隔离renderer构造完整AST/DOM；HTML携带本地媒体资源，LaTeX携带相对图片资源。DOCX/ODT/RTF/EPUB/LaTeX使用随包Pandoc。导出先完整暂存再原子发布，保护源码、未保存文档和外部新变化；导入使用sandbox及资源目录校验。
