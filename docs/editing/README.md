# 文档编辑

| 格式 | 内容源与主要能力 |
| --- | --- |
| Markdown | 单一源码；实时/源码/分栏、块、表格、公式图表、媒体、工作区与转换 |
| HTML | 源码、净化预览、节点/源范围；不等于任意网页富文本编辑 |
| DOCX / XLSX / PPTX | 原生 Writer / Calc / Impress；段落、表格、单元格、对象与样式 |
| PDF | 冻结字节与页面；文字提取/OCR、标记、页面与表单按能力提供 |

旧Office转换保留原件。原生会话是唯一可写模型，辅助投影用于读取与恢复，不能反向覆盖正文。

## 共同流程

读取目标 → 用ref修改 → 核对目标 → 显式保存。Agent参数保持扁平，不传内部身份；req标识逻辑修改，重试沿用原键，改变内容使用新键。

普通修改执行并读回；耗时操作返回job。效果、验证、恢复与落盘分别报告。保存确认冻结版本已写入，后续修改仍可能未保存。原生撤销使用当前token，文本撤销使用逆操作；不能覆盖后续编辑。

切换、关闭、导出及文件操作先排空草稿。改名、移动和回收拒绝未保存正文；外部新变化阻止覆盖。后台模型操作不主动切换人工页面，无法隔离的操作报告 unsupported。

## Markdown

实时、源码与分栏共享Text/ChangeSet、UTF-16范围与历史。分栏只读；无法精确映射的选区不提供写操作。回流校验身份与版本，迟到回执不能覆盖新选区。

源码与阅读共用响应式纸张宽度和页边距；正文、标题、代码、表格按统一比例排版。选区保留文字原色，使用淡透明底色；深浅主题遵循纸张颜色。

实时视图按已绘制文字定位鼠标。鼠标按住期间冻结语法显示，跨粗体、链接拖选不移动命中目标；松开后，光标或选区所在格式显示两侧源码符号。键盘进入也展开，离开后收起，选区仍绑定原始UTF-16范围。

表格、脚注、YAML、公式、图表、媒体及资源操作生成明确范围事务。未知语法保留原文。普通巨段输入走范围更新，IME 保留原生组合路径；装饰和重解析保持有界。

公式支持`$…$`、`\(…\)`行内，`$$…$$`、`\[…\]`块及math围栏；分数、矩阵、cases、aligned由MathJax排版，tex/latex围栏仍显示代码。开启自动配对后，独立`$$`、`\[`或代码围栏按回车补齐结束符并进入正文；已有结束符不重复补，整次补全可一步撤销。公式编辑显示源码框与下方预览，不等于完整TeX文档引擎。

HTML支持strong/b、em/i、u、s/del、mark、sub/sup、kbd、small、span文字样式与br换行，details/summary块经净化呈现。输入`<`或Ctrl+Space补全标签、属性和闭合标签；自动配对控制是否附带结束标签。点击正文显示原标签，分栏及导出保留原文，脚本和事件不执行。

图片支持粘贴、拖入、尺寸、相对路径与显式上传。未保存资源使用持久引用，保存后发布相对资产；普通粘贴不执行上传命令。路径须位于授权范围。

HTML/PDF/PNG 在隔离 renderer 构造完整导出内容；Pandoc 提供 DOCX/ODT/RTF/EPUB/LaTeX 转换。输出先暂存，校验后发布新文件，保护源码与外部变化。本地媒体有界流式读取并支持 seek。

界面与Agent共用导出服务；Agent先授权绝对新路径。来源版本变化或目标已存在则拒绝。

## 翻译

设置 → 翻译可选AI、Google Cloud Translation Basic、百度通用翻译和Azure Translator。Google填密钥，百度填APP ID与密钥，Azure填密钥及区域；普通服务无需AI连接。凭据由系统加密保存。

选区、网页及非 PDF 文档共用引擎选择；任务冻结启动时的服务与凭据。长文本按字符和 UTF-8 字节分段，百度请求串行限速；取消后忽略迟到结果。服务额度由对应平台管理。PDF 选区可用普通翻译，全文保版式输出仍需 AI 与 BabelDOC。

译文在正文底部以圆角矩形显示，70%不透明度、1px模糊、36px折射边缘、32px圆角、18px正文、宽高增长系数1.0；到边界后内部滚动。支持拖动形变、下拉收起和快捷键恢复。

## 扩展原则

按块、范围、表格、资源和原生对象提供语义操作。高级操作只有在真实执行与目标读回可用时才宣称支持。
