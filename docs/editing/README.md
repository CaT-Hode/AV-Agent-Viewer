# 文档编辑

| 格式 | 内容源与主要能力 |
| --- | --- |
| Markdown | 单一源码；实时/源码/分栏、块、表格、公式图表、媒体、工作区与转换 |
| HTML | 源码、净化预览、节点/源范围；不等于任意网页富文本编辑 |
| DOCX / XLSX / PPTX | 原生 Writer / Calc / Impress；段落、表格、单元格、对象与样式 |
| PDF | 冻结字节与页面；文字提取/OCR、标记、页面与表单按能力提供 |

旧 Office 转换保留原件。原生会话是唯一可写模型，辅助投影用于读取与恢复，不能反向覆盖正在编辑的内容。

## 共同流程

读取具体目标 → 使用返回 ref 修改 → 核对受影响目标 → 显式保存。Agent 参数保持扁平；无需重复传递内部 document/view/controller/epoch。req 标识同一次逻辑修改，重试沿用原键，改变内容须使用新键。

普通修改默认执行并读回；耗时操作返回 job。applied、verified、recoverable 与 saved 分开报告。保存确认冻结版本已写入源文件，后续实时修改仍可能未保存。原生撤销使用当前 token，文本撤销使用范围逆操作；都不能覆盖后续编辑。

切换、关闭、导出及文件操作先排空草稿。改名、移动和回收拒绝未保存正文；外部新变化阻止覆盖。后台模型操作不主动切换人工页面，无法隔离的操作报告 unsupported。

## Markdown

实时、源码与分栏共享 CodeMirror 的 Text/ChangeSet、UTF-16 范围与历史。右侧分栏只读；无法精确映射回源码的选区不提供写操作。回流校验身份与版本，迟到回执不能覆盖新选区。

表格、脚注、YAML、公式、图表、媒体及资源操作生成明确范围事务。未知语法保留原文。普通巨段输入走范围更新，IME 保留原生组合路径；装饰和重解析保持有界。

图片支持粘贴、文件拖入、尺寸、相对路径与显式上传。未保存资源使用持久引用，保存后发布相对资产；保存偏好与普通粘贴不执行上传命令。真实路径须位于授权范围。

HTML/PDF/PNG 在隔离 renderer 构造完整导出内容；Pandoc 提供 DOCX/ODT/RTF/EPUB/LaTeX 转换。输出先暂存，校验后发布新文件，保护源码与外部变化。本地媒体有界流式读取并支持 seek。

界面与 Agent 共用无对话框导出服务；Agent 先授权绝对新路径，导出不依赖人工窗口。来源版本变化或目标已存在则拒绝。独立隐藏 Electron 验证已覆盖 HTML/Markdown、源版本拒绝与新文件约束，未发送输入。

## 扩展原则

按块/范围、表格、资源和原生对象提供稳定语义操作，不把 UI 坐标或任意属性路径当作常用编辑 API。高级操作只有在真实执行与目标读回可用时才宣称支持。
