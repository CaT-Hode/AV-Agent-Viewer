# Markdown 写作

打开 Markdown 默认进入实时编辑。普通段落按 Enter 分段，Shift+Enter 在段内换行。列表和引用继续当前结构，代码、公式、YAML 各自保留原有换行规则。源码和分栏左侧适合逐行编辑。三个模式共享撤销和重做。

## 正文与命令

经典纸面使用 16 px 正文、1.6 倍行距和随桌面宽度变化的版心。写作偏好里的「中文长文」将字号调至 17 px 并缩短每行。标题、段距和字体也用于 HTML 和分页导出。目录从左栏打开，再点同一按钮收起。

空行输入 `/`，随后输入中文名称或英文关键词。上下键选择，Enter 确认，Esc 保留已输入的字符。鼠标移到行侧可用 `+` 插入或用块手柄整理。Ctrl+Alt+/ 直接打开当前块的命令菜单。列表项连同嵌套项、标题连同下级内容一起移动，支持拖动或选择上移、下移。正文选区工具优先显示格式、复制、翻译和提问，其他动作在「更多选区命令」。

实时视图优先粘贴剪贴板里的 Markdown，其次转换富文本的标题、列表、链接、样式和表格。Ctrl+Shift+V 粘贴纯文本，Ctrl+Shift+C 复制 Markdown。表格单元格聚焦后显示原始标记，Tab 切换单元格，粘贴多列 TSV 可以扩展表格。行列工具悬浮于表格上方。

## 引用、释义与导出

- `[[文件#标题|显示名]]` 支持相对路径、省略 .md 和同文档标题。Ctrl+点击打开，导出为普通链接。「写作偏好」可单独关闭双方括号链接。
- 术语后紧接一行 `: 释义`，可连续写多行冒号释义。实时编辑和分栏显示术语与缩进释义，HTML 使用 dl、dt、dd。
- `[@key, p. 12; @other]` 表示一组引文。在「导入与导出」选择本地文献库，可另指定 CSL 样式。导出时使用 Pandoc citeproc 排版引文与书目。未配置文献库时保留引文键，配置后的缺失键会指出具体条目。
- 公式、Mermaid、脚注、提示块、YAML、目录都可从插入命令进入。Markdown 导出保留源码。HTML、PDF、PNG 使用完整文档排版，Word、ODT、RTF、EPUB、LaTeX 使用 Pandoc。
