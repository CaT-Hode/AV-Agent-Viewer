# 当前能力与限制矩阵

Markdown以[Typora Windows](https://support.typora.io/Quick-Start/)、[语法](https://support.typora.io/Markdown-Reference/)及[导出](https://support.typora.io/Export/)为功能参照。已实现入口、代表样本通过与任意复杂文件完全兼容分别判断，不宣称完全对等。

| 模块 | 当前实现 | 当前限制 |
| --- | --- | --- |
| Markdown编辑 | 单源CodeMirror实时/源码/分栏，选区/历史、块ref与精确范围修改 | 分栏只读；未知语法保留源码；巨段仍有双解析长尾 |
| Markdown结构 | GFM、任务、脚注、TOC、YAML、可视表格、代码、MathJax、Mermaid、旧flow/sequence | 表格超过24000字符使用源码；语言包按需加载 |
| Markdown工作区 | 文件树/快速打开/搜索、大纲/统计/替换、专注/打字机/拼写/配对、主题/快捷键 | 文本内容扫描为主；未证明所有Typora行为一致 |
| 资源/转换 | 本地媒体Range、图片粘贴/拖入/尺寸/相对资产/显式上传；HTML/PDF/PNG与Pandoc五格式 | 受资源授权及已安装转换引擎限制；不自动上传 |
| HTML | 净化预览、源节点与文本/结构/白名单属性修改 | 排除脚本/活动表单；不提供任意网页富文本编辑 |
| Word | 原生段落/UTF-16范围、格式、命名表格/单格、命名页样式、评论/修订、段落文本比较 | 长单格须完整续读后写；比较不含格式；节级布局接口未提供；修订处理取决于引擎能力 |
| Excel | 原生范围/公式计算、格式、行列/工作表、合并、验证、排序/筛选、图表/透视 | 无跨操作原子批量；扩展对象按实时capability与读回判断 |
| PPT | 递归对象、隔离文字编辑、格式、幻灯片增删/复制/移动、备注/背景、母版与支持的动画、组合 | 文字编辑需隔离controller；媒体创建及完整布局接口未补齐；动画不是完整时间线；特殊控件需样本 |
| PDF | 独立冻结文字/页面渲染、范围查找ref、OCR坐标/来源、原生注释、页面增删/重排/旋转、命名表单 | 每页文字≤500项/16000字符并报告截断；阅读顺序部分；非安全涂黑/签名/原文重排 |
| 网页 | role/name检索、frame/元素ref、fill/select/check/wait、截图、本地阅读副本 | 不开放任意JS/CDP；敏感表单值排除；click派发不等于业务效果验证 |
| 工作台/AI | 来源定位、冻结证据集合、分块分析、覆盖报告、可取消任务、有界结果与恢复配额 | 全局跨文件事务、完整用户版本库不在当前能力内；取消不撤销已生效修改 |

## 公共调用闭环

MCP/HTTP/SDK/CLI共用扁平类型工具和请求校验，公开入口只保留v2。两工具起步，按类型及高级包渐进披露；单格式全部工具累计参考预算通过，实际宿主5k认证未通过；共享工具另计。

ref绑定来源、版本与具体目标，cursor绑定连接/查询/来源；req区分逻辑修改与重试。普通修改执行并局部读回，显式保存。后台操作保留人工活动页、焦点和选区，无法隔离时拒绝。

隐藏Electron语义验收已覆盖Word/Excel/PPT的读取→修改→重试→保存，Word表格完整续读/单格写与PDF范围/游标失效；跨域网页frame/元素读取也通过。接口实现不等于所有高级动作、复杂文件或外部网站业务流程已验收。系统输入验证已按用户要求停止。
