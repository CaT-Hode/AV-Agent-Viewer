# 代码审查 · 2026-10-19

本轮围绕 Word/PPT 文字编辑、选区识别、Office 首帧、浮栏与 Markdown 大文档完成重构。实现、用户流程验证和性能达标分别判断，计时及剩余瓶颈见[性能](performance/README.md)。

## 根因与处理

| 根因 | 已实施的处理 |
| --- | --- |
| Word/PPT 混淆对象、Outliner 文字、组合输入及模态状态 | 原子 inspect、明确能力判断；核对 session/epoch、选区和布局版本，丢弃迟到回执 |
| Office opening 被误报过期；同版本公开 withdrawn 状态覆盖可绘制几何 | 状态读取加入已有 opening；内部 surface 回执保留私有绘制几何，公开 SDK 继续受 presented/obscured 门槛约束 |
| 浮栏申请全文、纹理和几何测量阻塞点击 | 轻量 SelectionContext、即时命令、Worker 光学纹理、合并测量；低成本表面先可用 |
| Markdown 正文与左栏共用布局类，文件区缺少面板测量节点 | 独立正文容器与明确纸宽；文件区接入现有自适应测高，保留目录和查询状态 |
| 导航固定宽度、标题占位和每帧 React 更新 | 按真实内容量宽、可用空间决定密度；单个直接写样式的弹簧，运动复用纹理，无选区时浮栏不订阅导航几何 |
| 深色磨砂叠加白色内阴影与侧栏渐变 | 隐藏深色磨砂的装饰高光层，保留模糊、底色、外投影及焦点提示 |
| Markdown 巨行输入和片段回扫、全量装饰、预览等待 ACK | 明确范围的普通 insertText、保留原生组合输入；可视装饰、原生无竖线预筛、有界 fragment；Text/ChangeSet 直接投影 |
| 表格或代码缩进编辑复用错误节点；导出正则丢失嵌套或误认转义 | 仅失效命中的 fragment；live 与导出使用语法分隔符和侧界判断，保留强调、实体、转义与代码节点 |
| 历史、恢复和回执不断复制正文 | 文本逆操作、blob/delta、metadata 复用；有界 Worker 执行大正文编码/摘要和恢复导出，快照与回执执行前准入 |

快照按文档、总字节和数量保留，任务固定来源；回执默认每文档 64 MiB、总计 256 MiB。容量不足在执行前拒绝；旧超额记录仍可读取、保存和重放。首次冻结/差分、部分 metadata JSON 仍有主线程成本。

源范围与版本必须共同匹配。复制、引用、AI 使用冻结文本，过期写操作拒绝执行；Office 保持原生 lease。保存确认严格持久化屏障。文件及资源变更检查真实路径、未保存草稿与外部变化，回滚不覆盖外部新内容。导出在隔离窗口准备完整内容，暂存后原子发布。

## 验证与边界

常驻预算为常规 41、Electron 流程 6、真实 Kit 流程 3，共 50；扩展既有断言，不增加常驻探针。临时 fragment oracle 覆盖 60,167 例，14 处上游增量差异全部由窄 guard 修复，新增错误 0；内联边界另以 16 个定向样本核对 live 树与 HTML。具体用户流程见[测试](../tests/README.md)。

真实 Windows WeType 仅保留部分可信预编辑、中文输入及保存记录，结束事件标志和额外空格来源未判定；用户要求停止输入验证，三格式系统输入/历史闭环及新前台P95不记为通过。自动 composition 不能替代系统输入法。Typora 功能按[官方矩阵](editing/refactor.md)对标，复杂嵌套语法、主题 CSS、Office 排版及任意文件保真仍不能由少量样本推定。Core/App 的会话、命令和视图服务拆分仍需继续。
