# 代码审查与能力缺口

审查区分界面功能、可验证的语义操作、外部接口与实际验收。工具名称、原生命令目录或通过类型检查均不能单独证明功能闭环。

## 已定位问题

| 问题 | 处理方向 |
| --- | --- |
| MCP 全量注册、巨型操作 union | 单一 registry、两工具入口、按格式和高级包披露 |
| 多层身份与版本参数重复 | 服务端短 ref；req 独立，重试先查回执 |
| 列表、读取与任务携带整模型 | 元数据列表、有界范围、来源绑定游标、局部读回 |
| Agent 修改先完整镜像再提交 | 真实模型目标和原生 typed transaction，保存单独屏障 |
| Word/PPT 选区与对象文字混淆 | 原子 inspect、容器范围身份、独立 controller 能力检查 |
| Office 首帧与浮栏排队 | 交互优先、有界 worker、轻量选区、合并读取 |
| Markdown 巨段双解析和回扫 | 可视装饰、有界 fragment、Text/ChangeSet 直接投影 |

导航已按标题、域名、公式自适应；网址至少20字符宽。弹簧逐帧写样式，运动中复用纹理。空白 Markdown 保持纸宽，文件树/快速打开共用自适应测高。深色玻璃移除内部白色装饰高光。

10月20日统一DOM/原生网页选区浮栏：移除外壳重复磨砂和分离缩放，共用短进退时钟，保留解码后的光学层。选中底色与文字同步切换；输入框参考Kube Searchbox，文本独立于材质。分段滚轮直接更新真实偏移、可反向打断；精细像素事件和减少动态模式沿用系统滚动。屏外光学贴图按可见性生成。

选区译文改为正文底部居中的真液态玻璃圆角矩形，底色不透明度70%，高斯模糊1px，折射边缘36px、圆角32px，译文18px，按钮在两侧排列；长文按默认1.0的可配置系数同步增高增宽，到视口上限后滚动。Ctrl+Shift+Y可配置或关闭；开启后底部显示提示，向下拖动收起并保留结果。Agent提示叠在译文上方。全局hitbox合并DOM与原生浮窗实际边界，工具栏先避让，再移动或收起允许让位的浮窗；保护模态框与固定栏。

## 必须分清的边界

Word 评论/修订、Excel 图表/透视/验证、PPT 母版/支持的动画属性已接入类型化 API 和原生读回。代表样本通过不表示全部复杂对象通过；Word 比较仅处理段落文字，PPT 不提供完整动画时间线。

PDF 服务独立读取冻结字节，提供页面文字/位图、OCR 坐标与来源、范围检索、原生注释、表单和页面操作。文字按页有界并报告截断；安全涂黑、签名与原文重排仍不支持。

网页语义元素/frame ref 已绑定导航和 DOM 世代，连接游标隔离；后台读取及跨域层级验证通过。fill/select/check 有本地读回，click 仅声明派发，不能证明网站业务完成；不开放任意 JS/CDP。

AI 已支持冻结证据集合、分块分析、覆盖报告和有界任务结果；模型等待有180秒上限，取消后忽略迟到输出，不能保证外部服务已停止。恢复 blob/delta 不是用户可浏览的版本系统。

## 验证与后续

MCP 预算使用固定离线 tokenizer，检查每格式基础+全部高级闭包，并防止跨格式泄露。Codex 宿主包装、实际刷新与历史保留须另行认证，参考计数不冒充模型真实用量。

常驻测试总预算50，扩展既有职责。按用户要求停止输入验收；既有自动 composition 与局部计时不能证明系统输入法、整体 P95 或任意 Office 文件保真。当前结果以[测试记录](../tests/README.md)和[性能证据](performance/README.md)为准。
