# 代码审查 · 2026-10-16

本轮验收结果见[测试记录](../tests/README.md)。实现、通过的用户流程和尚未证明的性能目标分别记录，局部计时不代表整机达标。

## 根因与改动

| 问题 | 已实施的处理 |
| --- | --- |
| Word/PPT 文字编辑、选区和属性识别错位 | 分离组合输入、在途事件、Outliner 文字编辑与模态状态；原子 inspect 和明确能力判断 |
| 查询混用旧选区、旧视图或旧会话 | 核对 session/epoch/选区/布局版本；Host 丢弃迟到控制器回执，镜像等待后再次校验 |
| 首挂载被误报为会话过期 | 状态读取加入已有 opening；未绑定返回 NOT_READY，真实过期继续报告 |
| 按钮像未响应，浮窗等待全文或纹理 | 离散格式即时执行；轻量 SelectionContext；交互外壳立即可用，光学生成移 Worker |
| Markdown 大文件全量解析、传输和装饰 | 可视/活动块装饰、受影响区块更新、限制巨行片段回扫；MD/HTML 浮窗不再申请完整正文 |
| 每次操作复制历史和恢复正文 | 文本逆操作、历史/patch 字节预算、blob/delta 恢复和 metadata 复用；回执改为请求指纹 |

轻量选区捕获核对源码范围和版本；复制、引用、AI 保留冻结文本，写操作拒绝过期来源。Office 保持原生 lease。新增文件移动保留转义链接及根映射，关联变化或外部目标变化时拒绝；回滚不盲写外部新内容。旧回执迁移、v1 备份、损坏 blob 拒绝、GC 和 exclusive 恢复包导出均覆盖边界验证。临时图片连续缩放保留资源来源，净化仍使用默认协议限制。

## 验证边界

最终常规41、Electron流程6、真实Kit流程3全部通过；build与类型检查通过，Electron renderer errors=[]。Word预热后首次画面验证仍9.2 s、重开2.9 s，选区→工具单次493 ms，尚未满足全部性能目标。Markdown普通1/10 MiB输入P95 5.6–18.9 ms；10 MiB巨段102.4–117.7 ms且仍有128 ms长任务。真实点击稳定序列每模式10次，到结果P95约212–214 ms，不能据此宣布全部交互达标。

## 仍需收敛

- 冷启动与热引擎打开分布、复杂 mixed 属性和完整点击 P95 尚未证明；真实 Windows 拼音、复杂文件、主题/上传/Pandoc/导出保真仍需验收。
- Typora 官方矩阵已有广泛实现，当前回归不等于全部功能对标完成。
- Office 大文件创建视图前仍等完整 adapter.open 解析；该 Word 小样 reader_open 仅51 ms，不能解释后续5.8 s open RPC。原生辅助投影已延后到 presented。完整 Markdown 导出准备仍在主 renderer。
- Core/App 尚未完全迁移为会话、命令和视图服务。
- 正文编码/哈希仍有全文成本；receipt 键和恢复元数据随历史增长，统一容量预算未完成。
