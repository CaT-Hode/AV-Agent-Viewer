# 性能实现与边界

计时分清引擎、IPC、JS、下一rAF和物理呈现。局部微基准不推导整体加速比例；全部P95与物理帧率尚未证明达标。

## 已实施

- Office原子inspect、轻量选区、交互优先与可替代读取合并；内部可绘制状态保留私有几何，消除已定位的2500ms心跳等待。遥测不能阻断有效呈现。
- 大Office辅助模型进入有界Worker；ZIP同时估计展开XML。空闲按格式load、initialize、首瓦片、close预热，阶段间让路；执行中的LO调用不可抢占。
- Markdown明确范围的巨行普通输入、可视装饰、有界fragment和纯文本扫描；分栏直接消费Text/ChangeSet。快速Undo保序，迟到回流保留新Range。
- 浮栏不携全文；光学纹理计算/编码进入Worker，合并几何读取，长任务期间降低材质成本。
- 大正文编码/摘要、patch指纹及恢复导出进入有界Worker；blob/delta、逆操作、快照及回执准入减少复制。完整导出移至隔离renderer，流式复制媒体。

## 导航与布局 · 10月19日

导航测量唯一真实控件树中的标题、网址和公式；网址最小20ch，长公式扩展至可用宽度。按钮密度取决于可用空间，同一公式输入框保留草稿。

宽度和位置共用可中断弹簧，直接写CSS，取消逐帧React状态更新。运动中复用已解码光学纹理，停止后精确测量；无选区时浮栏不订阅导航几何。

空Markdown明确纸宽，文件区接入自适应测高。48种正文状态、11种左栏状态、22个跨格式导航快照通过；最终安装版12张深浅色截图验证去除内白圈、保留模糊与焦点。几何与视觉通过不等于帧率达标。
