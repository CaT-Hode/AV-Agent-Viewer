# 性能实现与证据

局部微基准与服务耗时不能证明整体P95、界面帧率或物理呈现达标。

## 当前处理

Office采用原生范围操作和局部读回，删除修改前重复镜像；修改后仍导出恢复检查点，保存独立。交互优先、合并读取、分阶段预热，复杂OOXML投影使用有界worker。已修复首帧2500ms心跳等待；已开始的LibreOffice调用不能抢占。

Markdown采用范围输入、可视装饰与有界解析；浮栏合并测量，导航弹簧直接写样式。恢复使用blob/delta与配额；Agent按格式披露、分页和局部读回。
