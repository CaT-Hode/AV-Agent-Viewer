# AI、证据与连接

阅读分析绑定明确来源。空选区不自动扩大为全文，可见范围不等于整篇；模型生成内容与源文档事实分开处理。

## 来源与任务

通过 `av_read` 读取有界内容，`av_evidence` 收集冻结引用，`av_ai` 发现或运行阅读分析，`av_task` 查询、取消与读取结果。类型工具由 `av_tools` 按需加载。

证据记录来源 ref、版本、位置、摘录和覆盖；部分提取、截断、OCR 与网页 frame 须保留来源说明。集合不会扩大文件授权。跨全文和跨文档分析采用分块，未读取部分不能冒充已覆盖。

job 仅表示任务身份。结果按页读取，不同时重复任务全文、原文与独立 Markdown。重试先查询原任务，沿用逻辑 req；取消不能撤销已发生的修改或外部效果。

分析默认不写原文，采纳结果使用具体目标重新提交。来源改变后旧证据仍能阅读，但不能绕过当前写入版本检查。

## 翻译

选区翻译可取消或固定，不进入原文撤销历史。全文翻译冻结发起时字节，创建独立同格式产物；后续原文修改不混入译文。PDF 全文翻译依赖 BabelDOC，复杂 Office 排版以产物检查为准。

网页翻译替换页面文字，可恢复仍未被站点修改的节点；布局变化后旧坐标失效。翻译不是网站表单提交，也不等于离线归档。

## 模型连接

支持 OpenAI Responses、Chat Completions 兼容服务和 Anthropic Messages；不同阅读流程可选择不同连接，在途任务保留发起时配置。

密钥由 Electron safeStorage 本地保存，读取和导出设置不返回明文。Codex 驱动使用独立 app-server 会话，不附着当前聊天。运行发现文件包含本地认证信息，只能交给受信任客户端。

MCP 不披露凭据或纯视觉偏好。文件权限只来自配置工作区根与已打开单文件；打开文件不授权其父目录。图片上传仍是明确的资源副作用，读取与保存偏好不自动执行命令。

## 能力边界

当前阅读分析与翻译已有界面流程；新增来源集合、覆盖与分块接口必须按实际执行器和回执验收。更多 AI 提示按钮优先级低于来源定位、任务生命周期和错误恢复。
